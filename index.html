Reto IA

  • Página web de FedeAtletismo resultante del prompt génerico - Promt simple: Crea el código HTML y CSS para mejorar la página de inicio de FedeAtletismo. https://fedeatletismo.org/
  • Página web de FedeAtletismo resultante del prompt elaborado - Prompt potenciado: Actúa como un desarrollador front-end experto. Genera un archivo único con HTML5 semántico y CSS3 incrustado para rediseñar la página de inicio de la Federación Salvadoreña de Atletismo (fedeatletismo.org). Utiliza una paleta de colores azul marino (#003366), blanco y acentos dorados/amarillos (#FFC107). La página debe contener: 1) Un Header fijo usando Flexbox con el logo (texto) y un menú (Inicio, Calendario, Atletas, Contacto). 2) Una sección 'Hero' con una imagen de fondo de pista de atletismo, un título inspirador y un botón CTA interactivo. 3) Una sección de 'Últimas Noticias' utilizando CSS Grid para mostrar 3 tarjetas (cards) que incluyan sombra, borde redondeado y efecto hover. 4) El diseño debe ser 100% responsivo usando Media Queries. Debes hacer un archivo CSS para el diseño, nada de asignar diseño y formato dentro del HTML, y añade comentarios breves en el CSS indicando las propiedades clave. También toma de referencia y guía estas capturas de la pantalla de inicio y, de paso, aquí tienes el código fuente HTML del sitio original de FedeAtletismo como contexto extra para mantener parte de la marca, pero mejorando estilísticamente las cosas que lo requieran. Y como última inspiración puedes tomar cosas del diseño del sitio de espn.com.
